# KPI Explorer

## Mission 300 Key Performance Indicator Explorer Specification

## A. Catalogue Summary

## These are catalogue and data-readiness summaries, not performance targets.

| Pillar or Scope | Metric or Dashboard Element | Visual Type | Information Icon Content: Definition, Methodology and Data Source |
|---|---|---|---|
| Key Performance Indicator catalogue | Total indicators | Summary card | Definition: Count of active indicators in the approved catalogue. Methodology: Count unique active Key Performance Indicator identifiers. Data source: Approved Mission 300 Key Performance Indicator Matrix. |
| Readiness | Core or Tier 1 indicators | Summary card | Definition: Indicators classified as immediate Minimum Viable Dataset priorities. Methodology: Count catalogue records classified Core or Tier 1. Data source: Approved Key Performance Indicator Matrix. |
| Readiness | Supporting or Tier 2 indicators | Summary card | Definition: Supporting indicators to be used where the source institution already maintains the data. Methodology: Count catalogue records classified Supporting or Tier 2. Data source: Approved Key Performance Indicator Matrix. |
| Data status | Indicators with a current value or data gap | Split summary card | Definition: Catalogue coverage by current data availability. Methodology: Count indicators with an approved current value separately from those marked as a data gap. Do not treat pending values as confirmed. Data source: Key Performance Indicator value repository and validation workflow. |

## B. KPI Catalogue

The Key Performance Indicator identifier is appropriate here because this page is the authoritative catalogue and technical drill-down.

| Pillar or Scope | Metric or Dashboard Element | Visual Type | Information Icon Content: Definition, Methodology and Data Source |
|---|---|---|---|
| Catalogue | Searchable Key Performance Indicator table | Table with identifier, name, pillar, category, unit, source institution, frequency, readiness, validation status and last update | Definition: Authoritative catalogue of dashboard indicators. Methodology: Display metadata from the approved catalogue. The identifier remains visible here for traceability but not on executive or pillar cards. Data source: Approved Key Performance Indicator Matrix and catalogue table. |

## C. KPI Profile

| Pillar or Scope | Metric or Dashboard Element | Visual Type | Information Icon Content: Definition, Methodology and Data Source |
|---|---|---|---|
| Profile | Definition, formula and unit | Structured profile panel | Definition: Official indicator metadata. Methodology: Show definition, approved calculation logic, unit, aggregation, frequency, disaggregation and limitations exactly as configured. Data source: Key Performance Indicator catalogue. |
| Profile | Baseline, current value, target and variance | Profile values with trend chart | Definition: Time-referenced indicator performance. Methodology: Use validated baseline, current and target records. Variance follows the configured direction of improvement and unit. Data source: Key Performance Indicator value, baseline and target repositories. |
| Profile | Source, validation and version history | Traceability panel | Definition: Origin and review status of the selected value. Methodology: Show source institution, source reference, submission, reporting period, validation decision, version and last update. Data source: Submission and validation records. |
| Profile | Linked implementation records | Linked programme, project, milestone and action table | Definition: Delivery records connected to the selected indicator. Methodology: Return approved register records linked through the indicator identifier. Data source: Implementation Register. |

## D. By Pillar and Readiness Tier

| Pillar or Scope | Metric or Dashboard Element | Visual Type | Information Icon Content: Definition, Methodology and Data Source |
|---|---|---|---|
| Analysis | Indicators by Compact pillar | Pillar distribution and selectable list | Definition: Indicator count and current data coverage by pillar. Methodology: Group unique catalogue records by pillar and separate indicators with confirmed, provisional, pending or missing values. Data source: Key Performance Indicator catalogue and value repository. |
| Analysis | Indicators by readiness tier | Core, Supporting and Future distribution | Definition: Indicator coverage by readiness classification. Methodology: Count unique active indicators by approved readiness tier. Data source: Approved Key Performance Indicator Matrix. |
