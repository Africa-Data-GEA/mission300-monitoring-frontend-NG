# Stakeholders & Institutions

## Mission 300 Stakeholders and Institutions Module Specification

## A. Institution Summary

These cards summarise the registry and reporting assignments. They are not performance targets.

| Pillar or Scope | Metric or Dashboard Element | Visual Type | Information Icon Content: Definition, Methodology and Data Source |
|---|---|---|---|
| Institution registry | Active institutions | Summary card by institution type | Definition: Institutions currently active in Mission 300 implementation, reporting or oversight. Methodology: Count unique active institution identifiers by approved type. Data source: Institution Registry. |
| Data custodians | Institutions with assigned datasets | Summary card | Definition: Institutions assigned responsibility for one or more data streams. Methodology: Count unique active institutions with an active dataset assignment. Data source: Institution Registry and dataset-assignment table. |
| Implementation | Institutions leading programmes or projects | Summary card | Definition: Institutions recorded as lead implementers. Methodology: Count unique lead institutions linked to active programme or project records. Data source: Implementation Register and Institution Registry. |
| Onboarding | Institutions pending onboarding or assignment | Summary card | Definition: Institutions not yet fully configured for their required role. Methodology: Count institution records marked Pending Onboarding or missing a required active assignment. Data source: Institution Registry. |

## B. Institutions

| Pillar or Scope | Metric or Dashboard Element | Visual Type | Information Icon Content: Definition, Methodology and Data Source |
|---|---|---|---|
| Registry | Institution catalogue | Searchable table | Definition: Official registry of ministries, agencies, regulators, utilities, Distribution Companies, generating companies, developers, partners, programme teams, custodians, validators and oversight institutions. Methodology: Show identifier, official name, type, status, coverage and last update. Data source: Institution Registry. |

## C. Data Custodians

| Pillar or Scope | Metric or Dashboard Element | Visual Type | Information Icon Content: Definition, Methodology and Data Source |
|---|---|---|---|
| Data responsibility | Dataset and reporting assignments | Responsibility matrix | Definition: Institutional responsibility for datasets, reporting periods and source evidence. Methodology: Link each active dataset to custodian, focal person, frequency, template, reviewer, validator and status. Data source: Institution Registry, dataset catalogue and assignment table. |
| Data responsibility | Priority federal custodians and streams | Institution-to-data map | Definition: Initial federal collection responsibilities. Methodology: Show Nigerian Electricity Regulatory Commission; Nigerian Independent System Operator and Transmission Company of Nigeria; Rural Electrification Agency; Federal Ministry of Power; and Federal Ministry of Finance assignments, separated by Tier 1 and Tier 2. Data source: Approved Priority Data Requirements by Institution. |

## D. Developers and Implementing Institutions

| Pillar or Scope | Metric or Dashboard Element | Visual Type | Information Icon Content: Definition, Methodology and Data Source |
|---|---|---|---|
| Implementation | Developers, programme teams and project owners | Linked institution table | Definition: Institutions involved in programme and project delivery. Methodology: Link institution records to their active programmes, projects, roles, coverage, financing where held and delivery status. Data source: Institution Registry and Implementation Register. |

## E. Roles and Responsibilities

| Pillar or Scope | Metric or Dashboard Element | Visual Type | Information Icon Content: Definition, Methodology and Data Source |
